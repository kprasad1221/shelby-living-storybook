# Interaction experiments

Ideas from KP for future work. The current `main` baseline remains the linear six-spread living storybook. None of the following are implemented yet.

- **Character interactions:** hover over a character to change which H3 clip plays. Provide tap and keyboard equivalents so it also works on phones and without a mouse.
- **Branching stories:** let a reader make a choice that leads to a different spread or sequence.
- **UI prototype discoveries:** carry useful interactions from small ChatGPT prototypes into the book, one experiment at a time.

Keep the book metaphor and reader-controlled pacing as the starting point. Develop experiments on separate branches so the working version remains easy to return to.
