UPLOAD WITH GITHUB DESKTOP (WINDOWS)

1. Download this ZIP to your PC, right-click it, and choose Extract All.
   Keep the extracted copy as your backup.
2. Install GitHub Desktop from https://desktop.github.com/ if needed.
   Sign in as kprasad1221.
3. In GitHub Desktop, choose File > Clone repository > URL. Paste:
   https://github.com/kprasad1221/shelby-living-storybook
   Choose a new local folder and click Clone.
4. Choose Repository > Show in Explorer to open the cloned folder.
   In another Explorer window, open the extracted shelby-living-storybook
   folder. Copy ALL its contents INTO the cloned folder. Replace the
   starter README.md when prompted.
   IMPORTANT: package.json must sit directly inside the cloned folder,
   next to README.md. Do not put an extra storybook folder inside it.
   The archive contains no .git folder, so the clone keeps its Git history.
5. Return to GitHub Desktop and review Changes. Enter this summary:
   Add complete six-video living storybook
   Click Commit to main, then Push origin.
6. Open the repository website and confirm it contains package.json,
   src/, public/, story.json, and docs/. Open:
   public/landing-pages/shelby-media/
   Confirm all six MP4s are present: warmth, room, carried, waiting,
   blanket, and together.

Do not upload the ZIP itself as your project source. Upload its contents.
If Desktop reports an error, keep the local folder and copy the exact
error into chat. No force-push or repository reset is needed for this flow.

RUN ON YOUR PC

Install a current supported Node.js LTS release from https://nodejs.org/.
Open a terminal in the cloned folder (the one containing package.json):

npm ci
npm run dev

Open the localhost address printed in the terminal. Stop with Ctrl+C.
For a production build: npm run build
For a local production preview: npm run preview
Opening index.html directly is not the development workflow for this app.
Node dependencies are intentionally excluded from this ZIP; npm ci installs
those listed in package-lock.json. Python is only needed to regenerate
page textures when changing the story artwork or baked-in text.
